## نمای کلی
این اپ یک الگوی دسکتاپ را برای موارد زیر نشان می‌دهد:
- گرفتن چهره‌ها با وب‌کم و تولید انکودینگ‌های چهره (با استفاده از `face_recognition`).
- ذخیره تصاویر، انکودینگ‌ها و متادیتا به‌صورت رمزنگاری‌شده روی دیسک (Fernet). فایل‌ها به‌صورت اتمیک نوشته می‌شوند و داخل ریشه مخزن در `face_guard_data/` نگهداری می‌شوند.
- اجرای پردازش دوربین در یک `QThread` برای اینکه GUI پاسخ‌گو بماند.
- تطبیق برداری (vectorized) انکودینگ‌ها برای عملکرد و مقیاس‌پذیری بهتر.
- یک GUI ساده (PyQt5) برای ثبت مدیران، مدیریت پروفایل‌ها و شروع حلقه مانیتورینگ.

این مخزن به‌صورت مشخص برای یک پروژه آموزشی/آزمایشی ساخته شده است — نه یک محصول امنیتی آماده‌ی تولید. برای جزئیات، بخش **امنیت / محدودیت‌ها** را ببینید.

---

## ویژگی‌ها
- جریان رمز عبور اصلی فقط از طریق GUI (بدون درخواست‌های کنسولی).
- ذخیره‌سازی رمزنگاری‌شده همه داده‌های کاربر با Fernet (مشتق‌شده از یک رمز عبور با PBKDF2-HMAC-SHA256).
- ذخیره انکودینگ‌ها به‌صورت numpy `.npz` فشرده قبل از رمزنگاری برای فشرده‌سازی و سرعت بهتر.
- نوشتن اتمیک فایل‌های رمزنگاری‌شده برای جلوگیری از نوشتن ناقص یا خرابی فایل.
- حذف امن با `shutil.rmtree` برای حذف مدیر.
- پردازش دوربین در `QThread` همراه با بک‌اند تطبیق برداری.
- تست‌های واحد پایه برای توابع کمکی.
- فایل `pyinstaller.spec` و نکات بسته‌بندی موجود است.
- فایل `logging.conf` برای نمونه لاگ‌گیری ارائه شده است.

---

## امنیت / محدودیت‌ها
- **این پروژه فقط برای یادگیری و استفاده محلی است.** آن را همان‌طور که هست در محیط‌های حساس تولیدی مستقر نکنید.
- کلیدهای مشتق‌شده در حافظه نگه داشته می‌شوند. صفرکردن حافظه انجام نمی‌شود.
- برای استفاده تولیدی واقعی، KMS / HSM و secure enclave پیشنهاد می‌شود.
- مدل `face_recognition` مبتنی بر dlib مناسب نمونه‌سازی است اما الزاماً مناسب امنیت جدی نیست.
- همه داده‌ها زیر `face_guard_data/` ذخیره می‌شوند تا چیزی بیرون از پروژه نشت نکند.

## نیازمندی‌ها
- Python 3.10+ توصیه می‌شود
- ابزارهای ساخت ++C برای dlib
- وجود دوربین
- نصب با `pip install -r requirements.txt`

`requirements.txt` شامل:
```
PyQt5
opencv-python
numpy
face_recognition
cryptography
pytest
```

## نصب (توسعه)
1. مخزن را کلون کنید یا از حالت فشرده خارج کنید.
2. محیط مجازی بسازید:
```bash
python -m venv venv
source venv/bin/activate
# ویندوز:
venv\Scripts\Activate.ps1
```
3. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

> در صورت خطای dlib یا face_recognition، مستندات رسمی را ببینید.

## اجرا (توسعه)
```bash
python run.py
```

اولین اجرا:
- ساخت master password از طریق GUI
- ثبت مدیران و شروع مانیتورینگ

محل داده: `face_guard_data/`

## بسته‌بندی (PyInstaller)
```bash
pip install pyinstaller
pyinstaller --onefile run.py --name face_guard --noconsole
```
پس از build، پوشه `face_guard_data/` باید کنار فایل اجرایی قرار گیرد.
